# @amlplugins/replicate-collections

Native `replicate` SDK re-exported under the `@amlplugins` namespace.

> Replicate Collections — list curated model collections (text-to-image, audio, video, language, multimodal).

## Install

```bash
npm install @amlplugins/replicate-collections
```

## Use

```ts
import { /* named exports from replicate */ } from "@amlplugins/replicate-collections";
// or
import sdk from "@amlplugins/replicate-collections";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
